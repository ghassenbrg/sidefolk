# Sidefolk 0.1.0 candidate notes

Development candidate; not a public or notarized release. Native acceptance is pending.

Pip and Spark keep your reminders, a dated work log and connected sessions close by.
The window now follows the approved paper-and-mint design, with a time-led Today agenda,
recent writing, a notebook index, compact capture and a separate four-pane Settings window.
Larger text, Quiet and reduced motion remain available.

Repeating reminders keep their anchors when snoozed. Multi-day weekly rules, yearly leap-day
confirmation, per-occurrence edits, complete history and picked snooze times are supported.
A reminder can wait for an exact project's next completion, with a visible 24-hour expiry.
Reminders fold after two minutes without answering or losing the held note.

Connected AI agents can control the companion and manage reminders and notebook entries
through MCP. Settings can install a small Sidefolk skill with a path preview, confirmation
and original-file backups. Codex session watching is opt-in Beta and requires /hooks trust;
approvals always remain in Codex.

Update installation is consent-based and verifies signed artifacts. An unsafe or unavailable
release policy releases held requests. Local data and logs stay on this Mac. Problem reports
are previewed before copying and contain only approved settings and diagnostic counts.

Known release limits: signing/update feed credentials, clean-install and native host tests,
VoiceOver/recording checks and the private-beta cohorts are still required. The configured
candidate version remains 0.1.0; a future release version must be set consistently in Cargo,
Tauri and package metadata before creating signed review artifacts.
