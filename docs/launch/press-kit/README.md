## Boilerplate

**Short (one sentence):** Sidefolk is a small companion for the Mac desktop that keeps your notes, reminds
you on time and watches pages and files, with or without AI.

**Medium (one paragraph):** Sidefolk puts a small character, Mochi the rabbit, on your Mac's desktop. You
tell it things in plain words and it keeps them: notes, reminders, pages and files to watch. The basics
run on your Mac with no AI and no account. For questions and bigger jobs it uses the AI you already have:
Claude Code, Codex, an API key, or a model running on your own Mac. Coding agents can leave it notes and
reminders over MCP. A fixed set of rules, not the AI, decides what it may do, and every action is listed
for you to see and undo.

**Long:** use the long description in [../DESCRIPTIONS.md](../DESCRIPTIONS.md).
