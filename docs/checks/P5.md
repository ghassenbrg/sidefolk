## Review

A separate Codex reviewer identified four issues: disconnect retries could reverse intent,
shortcut rollback removed the request shortcut, repeated summon lost the draft, and setup did
not hear its first health transition. Fixes include persisted removal direction, independent
shortcut registration, focusing existing input and first-heard integration events. A regression
uses a temporary settings store and a fake failing MCP operation; it never invokes an agent CLI.
An additional settings-lock lifetime issue was fixed by ending the direction-write guard before
performing connection edits. The follow-up found that hook whitespace clipping could join later prompt lines into history,
and that disabled recording left expired files on disk. First-line selection now precedes hook
clipping, with a hook→journal regression; the existing reminder tick independently prunes history.
Initial direction-save failure, stale hook snapshot and final pending-clear failure are injected
through the production orchestration helper. No external callback runs after the first two
failures, pending direction survives the last, and external work asserts the settings lock is free.

## Native checks for the founder

1. Open a notebook, leave capture text, press CmdComma, change settings, close Settings; the
   main window and draft should still be there. Close the main window; Pip should remain.
2. Summon, type a draft, summon again; Tab through suggestions. CmdShiftReturn should focus
   a waiting card without selecting Allow; Escape should return focus to the previous app.
3. Run Today→reminder→edit/delete→Undo→work log using keyboard and VoiceOver. Verify native
   text Undo inside fields and action Undo outside them, including Edit menu behavior.
4. Connect Claude through the app's own confirmation on an isolated profile; start a real
   session and verify setup changes from waiting to Working. Exercise Repair after moving the
   app and Finish disconnecting after an induced isolated failure. Never use the real profile
   for an automated development test.
5. With protection off/on, check a recording, screen share, Mission Control and two displays.
   Record acceptable/unacceptable, macOS version, window bounds, date and result. If acceptable,
   change the default to on; otherwise retain off and the setup choice (V1-X8).
6. Founder compares Today, Reminders, Work log, Sessions/review and Settings against approved
   mockups in both themes, then records design/accessibility gate decisions. Agents do not pass G4.
