# Shared memory

Notes that let any agent continue the work. Plain Markdown, kept short, committed with the code.

| File | Holds | Update when |
|---|---|---|
| [STATUS.md](STATUS.md) | Current task, checklist, next step, open questions | You start or stop work, or finish a checklist item |
| [DECISIONS.md](DECISIONS.md) | Product and technical decisions with reasons | A decision is made or reversed |
| [LEARNINGS.md](LEARNINGS.md) | Gotchas and how things really behave | Something surprised you |

Facts that the code, git history or docs already record do not belong here; link to them.
